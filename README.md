### GOshop - Full-Stack E-Commerce Platform

**Full-stack Developer | Individual Project**

**Tech Stack:** Go, Gin, PostgreSQL, SQLC, Redis, RabbitMQ, React, Next.js, TypeScript, Docker

A full-stack e-commerce platform built from scratch with a focus on clean architecture, scalability, reliability, and production-oriented backend engineering.

* Designed and implemented the **backend architecture using Go and Gin**.
* Built modular services for **authentication, products, inventory, carts, orders, payments, coupons, reviews, notifications, shipping, and analytics**.
* Implemented **JWT authentication, refresh tokens, token revocation, role-based authorization, and rate limiting**.
* Used **PostgreSQL with SQLC and pgx** for type-safe and efficient database access.
* Implemented **Redis caching and distributed application features**.
* Integrated **RabbitMQ and background workers** for asynchronous processing.
* Implemented payment workflows and **payment webhook handling**.
* Built the frontend using **React, Next.js, TypeScript, and TanStack Query**.
* Organized the frontend as a **Turborepo monorepo** with a storefront, admin dashboard, and shared API client.
* Added **OpenAPI-based API documentation and type-safe API integration**.
* Integrated **Grafana, Loki, and Promtail** for application observability.
